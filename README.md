
# A Multidimensional Evaluation Framework for Large Language Models Across Indian Languages

## Project Overview

This project aims to evaluate the quality of translations generated
by Large Language Models across Indian languages using a
multidimensional evaluation framework.

The framework investigates translation performance across different
languages and text domains.

## Research Objectives

- Evaluate semantic preservation in machine translations.
- Analyse sentiment preservation.
- Examine lexical and keyword similarity.
- Extend evaluation across Indian languages.
- Compare performance across literary and general-purpose texts.
- Identify translation errors and quality limitations.

## Reference Research

An Evaluation of LLMs and Google Translate for Translation of
Selected Indian Languages via Sentiment and Semantic Analyses.
