# TransEval 🌐
### A Multilingual LLM Translation and Evaluation Framework for Indian Languages

IndicEval is a multilingual AI-powered translation and evaluation system designed to translate text between English and five Indian languages: Hindi, Telugu, Tamil, Kannada, and Marathi.

The project aims to evaluate the quality of translations generated by different Large Language Models (LLMs) using a multidimensional evaluation framework that examines semantic preservation, sentiment preservation, linguistic quality, contextual consistency, and keyword preservation.

The system provides a unified interface where users can select translation models, generate translations simultaneously, and compare their outputs.

---

## 🎯 Project Objectives

- Develop a multilingual translation application supporting English and five Indian languages.
- Integrate multiple LLMs and machine translation services into a unified platform.
- Enable simultaneous translation using multiple selected models.
- Develop a multidimensional framework to evaluate translation quality.
- Compare translations based on semantic and linguistic characteristics.
- Conduct systematic benchmarking using curated parallel datasets.

## 🧠 Multidimensional Evaluation Framework

The project aims to evaluate translation quality across five dimensions:

| Evaluation Dimension | Description |
|---|---|
| Semantic Preservation | Measures whether the translated text retains the meaning of the original text. |
| Sentiment Preservation | Examines whether the emotional tone and sentiment are retained. |
| Linguistic Quality | Evaluates the fluency and linguistic quality of translated text. |
| Contextual Consistency | Examines whether meaning and context are maintained across sentences. |
| Keyword and Phrase Preservation | Checks whether important concepts and expressions are preserved. |

### Current Implementation

**Semantic Evaluation using LaBSE**

- Uses the Language-agnostic BERT Sentence Embedding (LaBSE) model.
- Generates multilingual sentence embeddings.
- Calculates cosine similarity between the original and translated text.
- Provides a semantic similarity score and an indicative interpretation.

The interactive translation workflow uses reference-free semantic evaluation. Research benchmarking will additionally use reference-based metrics wherever reference translations are available.

## ⚙️ Installation and Setup

Follow these steps to set up and run IndicEval locally.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/IndicEval.git
```

Navigate into the project directory:

```bash
cd IndicEval
```

### 2. Create a Virtual Environment

```bash
python -m venv .venv
```

### 3. Activate the Virtual Environment

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

**Windows Command Prompt:**

```cmd
.venv\Scripts\activate.bat
```

**Linux / macOS:**

```bash
source .venv/bin/activate
```

### 4. Install Dependencies

Run the following command from the project root directory:

```bash
python -m pip install --upgrade pip
```

Install all required packages:

```bash
python -m pip install -r requirements.txt
```

### 5. Configure Environment Variables

Create a `.env` file in the root directory.

Add the API credentials for the providers you intend to use:

```env
# OpenAI
OPENAI_API_KEY=your_openai_api_key
GPT35_MODEL=gpt-3.5-turbo
GPT4O_MODEL=gpt-4o

# Google Gemini
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-3.5-flash-lite

# Anthropic
ANTHROPIC_API_KEY=your_anthropic_api_key
CLAUDE_MODEL=your_available_claude_model

# Groq - Llama
GROQ_API_KEY=your_groq_api_key
LLAMA_MODEL=your_available_llama_model

# Google Cloud Translation
GOOGLE_APPLICATION_CREDENTIALS=credentials/google-translate-service-account.json
```

Replace the placeholder values with valid credentials and currently supported model identifiers.

For Google Cloud Translation, configure the Google Cloud project, enable the Translation API, and provide the appropriate service-account credentials.

**Security Note:** Never commit API keys or service-account credentials to GitHub. The `.env` file and credentials directory should be excluded using `.gitignore`.

### 6. Run the Application

Make sure:
- The virtual environment is activated.
- You are inside the `IndicEval` project root directory.
- Required dependencies are installed.
- The API credentials for the provider you want to use are configured.

Run the following command:

```bash
python -m streamlit run app.py
```

Streamlit will start the application and provide a local URL, usually:

```text
http://localhost:8501
```

Open this URL in your browser to access the application.

## 🧪 Running Tests

The project includes an independent test for semantic evaluation.

Run it from the project root directory:

```bash
python -m tests.test_semantic
```

This test evaluates the semantic similarity between an English sentence and its Telugu translation using LaBSE.

The first execution downloads the pretrained LaBSE model. An internet connection and sufficient disk space are required.

## 🔬 Research Direction

The project focuses on understanding how different language models preserve meaning, sentiment, and linguistic characteristics when translating between English and Indian languages.

A curated parallel dataset will be used for systematic benchmarking, while the interactive application will support translation evaluation without requiring users to provide reference translations.

The framework aims to provide a comprehensive comparison of translation quality across multiple models and Indian languages.
